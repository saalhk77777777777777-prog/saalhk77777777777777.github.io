Site Cloud Storage

사이트 자체 기록 동기화

Supabase 무료 DB를 붙이면 같은 방 키를 쓰는 기기끼리 작업 기록을 공유할 수 있습니다.

Supabase SQL Editor에서 아래 테이블을 한 번만 만들면 됩니다.
create table skybox_project_histories (room_key text primary key, payload jsonb not null, updated_at timestamptz default now());
Canva Helper

배경제거(캔바)

Canva는 보안 정책 때문에 이 화면 안에 직접 삽입되지 않아서 새 창으로 열립니다. Canva에서 배경제거 후 투명 PNG로 저장하고, 아래 버튼으로 다시 넣으면 됩니다.

1. Canva 열기

Canva에서 사진을 올리고 배경제거를 적용한 뒤 PNG 투명 배경으로 내려받으세요.

2. 결과 다시 넣기

다운로드한 PNG/WebP를 선택하면 현재 면에 이미지 레이어로 추가됩니다.
